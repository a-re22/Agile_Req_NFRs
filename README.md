# Agile_user_story_NFRs
Pre-trained Models for Identifying NFRs in Agile User Stories
--------------------------------
# Labels:
Abbr.	Label

FR: Functional

CM: Compatibility

MN: Maintainability

SE: Security

PE: Performance Efficiency

PO: Portability

RL: Reliability

US: Usability

--------------------------------

Abbr.	Label	Related Attributes

FR	 (Functionality feature)

CM	 (Co-existence, Interoperability)

MN	 (Modularity, Reusability, Analyzability, Modifiability, Testability)

SE	 (Confidentiality, Integrity, Accountability, Authenticity, Non-repudiation)

PE	 (Time-behavior, Capacity, Resource utilization)

PO	 (Adaptability, Installability, Replaceability)

RL	 (Availability, Recoverability, Fault tolerance, Maturity)

US	 (Operability, Learnability, User interface aesthetics, Accessibility, Appropriateness recognizability, User           error protection)
